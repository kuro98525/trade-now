trade-now 站点上传说明（给运维 / 帮忙上传的人）
================================================================

一、要上传的文件
----------------------------------------------------------------
trade-now-deploy.zip（约 200 KB）

解压后是这些，请把【解压出来的内容】直接放到站点根目录：

    index.html          ← 入口文件 70,369 字节，必须在根目录，不能改名
    assets/logos/*.jpg|png  （20 个交易所 logo）
    assets/telegram.svg
    .nojekyll           ← 防 Jekyll 的空标记文件，留着无害

正确：/www/wwwroot/你的域名/index.html
错误：/www/wwwroot/你的域名/trade-now-deploy/index.html   ← 多套了一层目录，会 404

二、服务器要求
----------------------------------------------------------------
1. 纯静态站点，不需要 PHP、不需要 Node、不需要数据库。
2. 必须开 HTTPS（iOS / 微信 / Telegram 的 WebView 对 http 有各种限制，
   补丁里的跳转方案在 https 下才稳定）。
3. 【重要】不要给 index.html 加 X-Frame-Options 或严格 CSP，
   页面内部用 iframe / srcdoc 渲染，加了会白屏。

三、Nginx 参考配置（Apache 用 RewriteRule 同理）
----------------------------------------------------------------
server {
    listen 443 ssl http2;
    server_name 你的域名;

    root /www/wwwroot/你的域名;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # index.html 不要长缓存，否则客户端拿到旧版本
    location = /index.html {
        add_header Cache-Control "no-cache, must-revalidate";
    }

    location /assets/ {
        add_header Cache-Control "public, max-age=2592000, immutable";
    }

    gzip on;
    gzip_types text/html text/css application/javascript image/svg+xml;
    gzip_min_length 1024;
}

宝塔 / aaPanel：添加站点时选「纯静态」，然后在「SSL」里一键申请
Let's Encrypt，打开「强制 HTTPS」，再按上面第 1 条放文件即可。

四、上线后自检（三步，1 分钟）
----------------------------------------------------------------
1) 浏览器打开 https://你的域名/ ，应看到深色落地页，无白屏、无 404。
2) 手机浏览器打开同一地址，页面正常，不弹任何遮罩
   （正常浏览器不该弹，说明识别逻辑没误伤）。
3) 命令行验证补丁已生效：
     curl -s https://你的域名/ | findstr x-safari-https
   （Linux 用 grep）有输出即成功；无输出说明 index.html 传错了或没解压。

五、常见问题
----------------------------------------------------------------
Q: 打开是空白页 / 只有背景没内容？
A: 多半是文件放错层级（多套了一层目录），或 nginx 没配 try_files。

Q: 提示 403 / 500？
A: 站点被当成 PHP 站点跑了。改成「纯静态」，并确认目录权限 www:www 755。

Q: 页面能开但手机点开没反应、也没遮罩？
A: 先看是不是 http 而不是 https；再确认 index.html 是 67,567 字节左右
   （被 CDN / 面板压缩改写过的版本可能异常，重新原样上传一次）
   本包内 index.html 为 70,369 字节，SHA256 前 8 位 B059C731。。

Q: 需要我改域名 / 端口 / 目录？
A: 这个包不含域名配置，任何域名都能直接用，不需要改代码。
